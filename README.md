# docx-editor-example

One page rendering `layout-C-student.docx` in the official
[`@docx-editor.dev/react`](https://github.com/eigenpal/docx-editor) editor —
the floating seal-line table (`w:tblpPr`) repro for the layout issue.

## Run locally

`npm install` then `npm run dev` — the app fetches the .docx straight from
the repo root.
